# 2026-09-14 涨停板数纠正记录

## 已确认原因

1. 炸板池不提供 lbc，zttj 不含今天未封住的一板，不能直接用它作为今天连续板数。
2. 播报完整列表将历史炸板也计入几天几板，并覆盖当天上游标签。超声电子因此从6天4板变成6天5板。
3. 同花顺6天4板等间隔标签被错误写入 continuous_limit_up_days=4。
4. 连板字段未知时多个后端/前端路径默认1，错误播报首板。

## 修复规则

- 连续板数与几天几板标签分开传递；当天来源标签优先。
- 炸板优先保留当天已确认板数，否则使用前一实际交易日的收盘复盘。前日未封住不算连续板。
- 历史记录缺失不推断首板；无确证时返回未知并仅播涨停。炸板池明确0天0板才确认首次触板。
- 历史回退只计收盘封板；同花顺间隔标签不再当作连续板数写库。
