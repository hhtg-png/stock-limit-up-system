# 涨停监控：昨日封板与开盘竞价

用户已确认直接实施四列，并同步手机卡片和 CSV 导出。

- 昨日首封、昨日终封：所选实际交易日前一交易日的首次、最后封板时间，HH:mm:ss。
- 昨日竞价、今日竞价：各交易日最终开盘价相对该日行情参考昨收价的涨幅，带正负号、两位小数和 %；真实零显示 0.00%。不使用盘中涨幅。
- 昨日由交易日历确定；历史查询及数据回退均以实际数据日期为锚点。昨日未触板、无开盘数据等空值显示 —。
- 在现有列表增加字段，不增加新页面。桌面四列、手机卡片、CSV 使用一致格式。

## Approach

用户选择直接扩展现有列表。沿用实时腾讯批量行情获取当日 open/pre_close；历史日线补齐昨日与历史查询开盘涨幅。历史未复权日线的 close-change_amount 作为同日参考昨收，防止除权口径混用。昨日封板优先批量读取数据库事实，必要时补查历史涨停池。历史补充按日期和股票缓存、限制并发和等待；不阻塞已有告警快速通路。实时富数据和 HTTP 均携带四字段，推送保留一致性。
